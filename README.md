# Taller Mecánico Completo

Este repositorio contiene el desarrollo del modelo completo de un taller mecánico.

## Descripción del Proyecto

Vamos a crear el modelo completo del taller mecánico, ejercicio correspondiente al módulo **Programación Orientada a Objetos Seguro** del **segundo semestre del año 2026**.

## Objetivos
- Diseñar e implementar las clases y relaciones que modelan el funcionamiento integral de un taller mecánico.
- Aplicar principios de Programación Orientada a Objetos (POO):
  - Encapsulamiento
  - Herencia
  - Polimorfismo
  - Abstracción
- Incorporar buenas prácticas de desarrollo seguro y validación de datos.
